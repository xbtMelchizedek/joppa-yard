# Security

Report vulnerabilities privately. Do not open a public issue for a security finding.

Email: use a private channel to xbtMelchizedek, or open a private GitHub security advisory on this repository.

This project never logs, commits or prints wallet seeds, gateway bearer keys or keystore passphrases. Receipts may carry public request ids, spend amounts and channel ids, not credentials.

Do not point the live provider at mainnet. Testnet only, with a testnet-only key.
